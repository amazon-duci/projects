# 🇳🇬 2023 Nigerian Election Analysis

This Excel project analyzes the **2023 Nigerian election results** at the state and local government levels.  
It provides visual insights into party performance, stronghold areas, and regions where parties could focus more effort in upcoming elections.

---

## 📌 Project Overview
**Objective:**  
- Highlight the geographical and numerical distribution of votes by party.  
- Identify party **strongholds** and regions with weaker performance.  
- Help political parties **strategize future campaigns** based on past performance.

---

## 📂 Files in This Project
- **Election Dataset** → Different sheets containing raw 2023 election results, analyzed dataset and pivot tables, charts, and slicers for interactive analysis.    
- **Screenshots**  → Visual reference for dashboards.

---

## 🔧 Methodology
1. Imported raw election results into Excel.  
2. Cleaned and structured data for pivot table analysis.  
3. Created interactive **state-wise and party-wise visualizations**:
   - Vote distribution by party  
   - Total votes per state  
   - Party strongholds vs weaker areas  
4. Used conditional formatting and slicers to allow quick insights on specific states or parties.  
5. Summarized recommendations for parties based on vote gaps and stronghold consolidation.

---

## 📊 Output / Insights
- **Party strongholds:** Clearly highlight states and constituencies with high vote concentration.  
- **Opportunity regions:** Identify areas where additional campaign efforts could be effective.  
- **Trend visualizations:** State-wise comparisons and historical patterns for strategic planning.

---

## 🚀 Use Case
- **Political parties:** Can use this analysis to focus resources on regions needing more engagement.  
- **Campaign teams:** Quickly understand strengths and weaknesses at a state and constituency level.  
- **Researchers and analysts:** Study electoral trends and regional performance patterns.

This project helps translate raw election data into **actionable insights**, improving campaign planning and strategic decision-making.
