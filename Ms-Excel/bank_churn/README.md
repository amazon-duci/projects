# Bank Churn Analysis

This project analyzes **bank customer churn data** using Microsoft Excel.
It focuses on understanding customer behavior, identifying churn patterns, and visualizing key factors that influence customer retention.

---

## 📌 Project Overview
**Objective:**  
Explore and analyze customer churn data to determine why customers leave the bank and identify patterns that can support retention strategies.

**Key Questions Addressed:**
- What percentage of customers are churning?
- Which customer segments are most likely to churn?
- How do factors like balance, tenure, and credit score affect churn?

---

## 📂 Files in This Project
- **Bank Churn messy** → Raw customer data used for analysis.
- **Bank Churn Data dictionary** → explanation of the details of the information in the raw dataset.
- **Churn Analysis clean** → Excel file containing cleaned data, pivot tables, and visualizations.

---

## 🔧 Methodology
1. Inspected and cleaned the dataset for missing or inconsistent values.
2. Categorized customers by demographics and account features.
3. Used pivot tables to analyze churn across multiple dimensions.
4. Built charts to visualize churn patterns and trends.
5. Summarized insights for easier interpretation.

---

## 📊 Output
- Visual breakdown of:
  - Churn vs retained customers
  - Churn by gender, geography, and tenure
  - Relationship between account balance and churn
- Clear insights into high-risk customer segments.

---

## 🚀 Use Case
This analysis supports **banking and financial institutions** in understanding customer churn behavior and designing targeted retention strategies based on data-driven insights.
