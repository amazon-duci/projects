# Adidas US Sales Dashboard

This project presents a **dynamic Excel dashboard** analyzing Adidas sales performance across the United States.
It transforms raw sales data into clear business insights using interactive visuals and KPIs.

---

## 📌 Project Overview
**Objective:**  
Analyze Adidas US sales data to understand revenue trends, regional performance, and product-level insights.

**Focus Areas:**
- Total sales performance
- Regional and state-level analysis
- Product and category contribution
- Time-based sales trends

---

## 📂 Files in This Project
- **Adidas Sales Dataset** → Raw sales data used for the analysis.
- **Adidas Dashboard** → Interactive Excel dashboard with slicers, charts, and KPIs.

---

## 🔧 Methodology
1. Cleaned and structured the raw sales data.
2. Created pivot tables for aggregation and analysis.
3. Built KPIs for key metrics such as total revenue and sales volume.
4. Designed interactive charts and slicers for dynamic filtering.
5. Linked visuals to allow user-driven exploration of the data.

---

## 📊 Output
- Interactive dashboard displaying:
  - Total sales and performance metrics
  - Regional and state-level sales breakdown
  - Product/category contribution to revenue
  - Time-based trends

---

## 🚀 Use Case
This dashboard helps **sales managers and business analysts** quickly assess performance, identify strong and weak regions, and make data-driven decisions to improve sales strategy.
